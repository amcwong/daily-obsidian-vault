# Style guide

Vault-wide conventions, including naming, folder prefixes, and hotkeys. This folder is **unprefixed on purpose**: it is infrastructure, like `dev/`, not a daily working surface.

## Conventions

- [[folder-prefixes]] — `!` / `~` / `π` sort folders by how often you use them
- [[naming]] — `-` or `_` in folder names, never spaces
- [[hotkeys]] — Cmd-Shift-D / Y / ; / A, and optional GitHub backup

Folder Notes (left-click a folder to open its note) is documented in `dev/obsidian-config/folder-notes-and-nesting.md`.
