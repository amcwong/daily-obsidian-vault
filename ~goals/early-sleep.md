# Sleep early enough

## What this goal is

Protect a consistent lights-out so the next day is not already behind. “Early” means your chosen cutoff, not a universal time.

## How I want to achieve it

- Set a cutoff you can repeat on weeknights.
- Log `1` if you hit it, `0` if you did not.
