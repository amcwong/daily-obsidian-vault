# Style guide

Vault-wide conventions for naming and folder prefixes. This lives under `dev/` because it is infrastructure, not a daily working surface.

## Conventions

- [[folder-prefixes]] — `!` / `~` / `π` sort folders by how often you use them
- [[naming]] — `-` or `_` in folder names, never spaces

Hotkeys: [[dev/docs/hotkeys]]. Setup problems: [[dev/docs/common-issues|common issues]]. Todoist: [[dev/docs/todoist-setup|Todoist setup]].

Folder Notes (left-click a folder to open its note) is documented in `dev/obsidian-config/folder-notes-and-nesting.md`.
