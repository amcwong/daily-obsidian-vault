# Todoist

The task app this vault pairs with. Plugin install: [[dev/docs/todoist-setup|Todoist setup]]. App shortcuts are also listed in [[dev/docs/hotkeys|hotkeys]].

These keys and tricks work in the **Todoist app**, not inside the Obsidian embed.

## Shortcuts

| Key | Action |
|---|---|
| `q` | Quick Add a new task |
| `m` | Toggle the sidebar |

## Adding a task

In Quick Add (`q`), type the title and the extras in the same field. Todoist pulls them out:

- **Date** — `today`, `tomorrow`, `aug 30`, `every monday`
- **Priority** — `p1` (highest) through `p4` (lowest, the default)
- **Project** — `#project-name`
- **Label** — `@label`

Example: `Call dentist tomorrow p1 #Health`

Complete tasks in Todoist. The daily note only displays them.
