# Hotkeys

These are the shortcuts this vault is set up around (macOS). `Mod` is Command.

| Shortcut | Action |
|---|---|
| Cmd-Shift-D | Open today’s daily note |
| Cmd-Shift-Y | Open the previous daily note |
| Cmd-Shift-; | Jump to the next Templater cursor (`Today` → `Yesterday`) |
| Cmd-Shift-A | Toggle the left sidebar |

**Optional:** Cmd-Shift-P to push a backup to GitHub (Obsidian Git). Setup: [[dev/docs/quick-start|quick start]]. This public vault does not enable that plugin by default. If you install it, bind **Git: Push** to Cmd-Shift-P (or Cmd-Ctrl-Shift-P if Cmd-Shift-P is already the command palette).

Heading shortcuts Cmd-Alt-1…6 are also in `.obsidian/hotkeys.json`. Cmd-Shift-S toggles the right sidebar.

## Todoist

These work in the **Todoist app**, not in the Obsidian embed. Quick reference: [[dev/docs/todoist|Todoist]].

| Key | Action |
|---|---|
| `q` | Quick Add a new task |
| `m` | Toggle the sidebar |
